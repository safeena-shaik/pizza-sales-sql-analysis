# Intermediate SQL Analysis

This folder contains intermediate-level SQL queries used to explore pizza sales patterns, product categories, and daily ordering trends.

The analysis focuses on using table joins, aggregations, date and time functions, and grouping techniques to extract meaningful business insights.

### Queries Included

1. **Quantity by Pizza Category** – Calculates the total quantity of pizzas ordered for each pizza category.
2. **Orders by Hour** – Determines the distribution of orders across different hours of the day.
3. **Pizza Category Distribution** – Analyzes the distribution of pizzas across different categories.
4. **Average Pizzas per Day** – Groups orders by date and calculates the average number of pizzas ordered per day.
5. **Top 3 Pizzas by Revenue** – Identifies the three pizza types generating the highest revenue.

### SQL Concepts Used

* `JOIN`
* `SUM()`
* `COUNT()`
* `AVG()`
* `GROUP BY`
* `ORDER BY`
* `LIMIT`
* Date & Time Functions
* Aggregate Functions
* Subqueries
