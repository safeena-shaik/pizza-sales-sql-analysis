# Advanced SQL Analysis

This folder contains advanced SQL queries focused on revenue analysis, revenue trends, and ranking pizza performance within each category.

For this level, I used **AI agents as a supporting learning tool** to help understand and develop solutions for more complex SQL concepts. I reviewed, tested, and refined the queries against the dataset to understand how the logic works and ensure the results were accurate.

### Queries Included

1. **Revenue Contribution Percentage** – Calculates the percentage contribution of each pizza category to the total revenue.
2. **Cumulative Revenue Over Time** – Analyzes cumulative revenue generated over time using window functions.
3. **Top 3 Pizzas by Revenue per Category** – Identifies the top three revenue-generating pizza types within each pizza category.

### SQL Concepts Used

* Window Functions
* `RANK()`
* `SUM() OVER()`
* `PARTITION BY`
* `ORDER BY`
* Subqueries
* Aggregate Functions
* Percentage Calculations
* Cumulative Calculations
* `GROUP BY`
